# Beispielsammlung für BrowsEye

Dieser Ordner zeigt die Struktur eines Ausstellungs-Pakets. Er verwendet bewusst das eingebaute Architektur-Demomodell und enthält keine Museums- oder Partnerdaten.

Für ein echtes Paket wird im Abschnitt `source` des Manifests `"kind": "file"` verwendet. Das präsentationsfertige GLB kommt dann beispielsweise unter `model/exponat.glb` in denselben Paketordner.
